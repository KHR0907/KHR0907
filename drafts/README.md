| 순서 | 템플릿 | 특징 |
|---:|---|---|
| **1** | **[Final Hybrid](./README-1-final-hybrid-template.md)** | **최종 선택. 채용형 소개 + 시스템 관점 + 대시보드** |
| 2 | [Recruiter First](./README-2-recruiter-first-template.md) | 읽기 쉬운 소개와 프로젝트별 상세 설명 |

## 참고한 공개 프로필의 방향

- [Sindre Sorhus](https://github.com/sindresorhus): 짧은 정체성과 작업물 중심의 극단적 미니멀리즘
- [Anthony Fu](https://github.com/antfu): 개인 사이트로 이어지는 간결한 링크 허브
- [Cassidy Williams](https://github.com/cassidoo): 말투와 취향이 드러나는 인간적인 소개
- [Addy Osmani](https://github.com/addyosmani): 현재 관심사·협업 주제·연락 방법을 빠르게 전달
- [Kent C. Dodds](https://github.com/kentcdodds): 프로필을 개인 브랜드의 명확한 입구로 사용
- [GitHub 공식 가이드](https://docs.github.com/en/account-and-profile/tutorials/using-your-github-profile-to-enhance-your-resume): 프로젝트를 방문자가 빠르게 이해할 수 있도록 설명

> 공개 프로필의 문구나 디자인을 복제하지 않고 정보 구조와 전달 방식만 참고했습니다.
